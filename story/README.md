# Story

This directory contains narrative-specific information. It is intentionally separate from objective setting truth in [`../canon/`](../canon/README.md).

## Areas

- [`projects/`](projects/README.md): one directory per novel, series, or other narrative project
- [`character-knowledge/`](character-knowledge/README.md): what a character knows, believes, suspects, or misunderstands at a given point
- [`reveals/`](reveals/README.md): when information becomes available to readers or characters
- [`chronology/`](chronology/README.md): narrative ordering and story-relative timelines

A statement in `story/` does not establish canon merely because a narrator or character asserts it. Link to canon pages when the narrative depends on objective setting facts.
