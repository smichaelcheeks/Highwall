# Author-Facing Lore Seed Template

## Author instruction

The author approved the immediately preceding proposal with: `Let's build that.`

## Session mode

`direct-integration`

## Submitted information

The approved proposal was to add a dedicated author-facing template that can be
given to ChatGPT with the instruction to interview the author or organize raw
lore into a clean seed document. The proposed template would include:

- a reusable ChatGPT instruction block
- explicit canon authority and session mode
- source-versus-belief distinctions
- organized facts and relationships
- ambiguities and unresolved questions
- story-only or reveal-sensitive information
- a prohibition against filling gaps
- a clean verbatim-seed output format

The template is distinct from the repository's existing internal intake wrapper.
