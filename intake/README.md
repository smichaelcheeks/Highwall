# Intake

This directory preserves submitted sources for stitches before they are
classified and woven into the CLOTH.

- [`submissions/`](submissions/README.md): immutable source documents supplied for review

An intake submission is evidence of what was provided, not an authoritative canon page. Its contents become canon only when authorial authority is clear, the review assigns an approved disposition, and the appropriate page under [`../canon/`](../canon/README.md) is created or updated.

An initial stitch submission and its later conversational addenda share a
stable case ID. This groups their history without modifying the source or
collapsing later decisions into the original submission.

Processing decisions belong in [`../development/intake-reviews/`](../development/intake-reviews/README.md), not in the submission itself. See [`../references/intake-workflow.md`](../references/intake-workflow.md).
